# 方案：自动批量下载原文＋待获取队列（草案）

> 2026-10-06 起草（经主笔确认设计方向）。目标：把「缺文清单」里能合法自动拿到的原文直接拿回来（下载→入库→挂链），拿不到的进「待获取队列」流水线化人工获取。

## 一、定位与红线

- **目标**：自动清大头；人工只保留"点开→下载"两个动作，其余（归位／起名／记账／挂链）全部由工具完成。
- **红线**：只对**合法开放获取**来源（arXiv／出版社 OA／机构仓库／PMC）发起自动下载；**不集成、不设计任何绕过付费墙或反抓取措施的功能**（含"人工辅助过墙"类方案）。付费墙残余全部走人工渠道（图书馆／文献传递／作者）＋「下载认领」入库。
- **前置**：先跑「可获取性筛查」量化自动可达比例（即下载解析阶段），再决定人工投入；本轮「全集联网比对」应用后 `download_url` 就位，解析命中率最高。

## 二、如何下载（解析链 → 下载核心）

**解析链（逐层优先）**：

1. arXiv：`eprint`（ADS 可补）或 `download_url` 中的 arxiv 链接 → `arxiv.org/pdf/<id>`；
2. 记录已有 `download_url`；（OpenAlex 的 arXiv／仓库／出版社 OA 直链）
3. 现场重解析：OpenAlex（DOI／标题）→ best_oa_location／仓库 PDF；可选 **Unpaywall**（免费，需 `.env` 加 `PRIMER_UNPAYWALL_EMAIL`）；
4. 无 → 判「仅付费墙／暂无 OA」，不自动尝试。

**下载核心**（吸取既有下载截断事故的教训，全部内容级校验）：

- 后台队列：1–2 路并发＋按主机限速；UA 标识；429／Retry-After 退让；重试 ≤2 次；
- 校验：`%PDF` 头＋尾部 `%%EOF`＋`pdfinfo` 可解析出页数；HTML／登录页／挑战页（content-type 或魔数不符）一律判「疑似需人工」，**不放垃圾进库**；
- 原子落地：`.part` 临时名 → 校验通过再改名；失败清理；大小上限＋磁盘检查；
- 去重：目标目录与全库按 md5／DOI 跳过（现有已关联文件天然去重）；
- 日志：`下载日志.csv`（记录／URL／结果／大小／耗时／原因）。

## 三、文件归置

- **目标目录**：对话框中可选（系统文件夹选择器，记住上次）；默认取「现存已关联文件最集中的目录」（本库场景即 `参考资料/参考文献原文/`），无则 `<库目录>/下载/`；
- **命名**：`<短标题>_<年份>.pdf`（净化非法字符、限长；撞名自动 `-2`）；
- **登记与挂链**：落地即登记为文件记录（md5 查重）并直接挂链回源记录；性质新增枚举 **`auto-download`**；
- **解析**：下载后自动 MinerU 解析**默认关**（避免几百条挤爆解析队列，可事后挑选重解析）。

## 四、付费墙：三类分流

| 类别 | 处理 |
| --- | --- |
| 绿色 OA（arXiv／仓库版） | 自动下载（预计大头） |
| 金色 OA（出版社直链） | 自动下载 |
| 纯付费墙（含中文库；403／需登录） | 不自动尝试 → 进「待获取队列」，四渠道分流：图书馆／文献传递（NSTL）／作者索取／本人浏览器 |

## 五、待获取队列（人工获取流水线化）

1. **队列生成**：从「缺文清单」一键生成条目（题名／年／DOI／下载页／渠道）；按渠道分组，可导出各渠道 CSV 子清单（给图书馆的即现成工单）。
2. **存储**：库旁车文件 `<库名>.acquire.json`（与 `.projects.json` 同款），条目 `{record_uuid, channel, status, note, updated_at}`；`status` ∈ `pending/submitted/done/failed/skip`；库 JSON 保持纯书目。
3. **工作台**：中栏新增「获取」标签页——每行一条待办＋[打开下载页]（顺手复制 DOI）＋[已获取]／[换渠道]／[无法获取]；做完自动落下一条；页头显示各渠道计数（进度板）。
4. **下载认领（免归位、免记账——省时间的关键件）**：设定「收件箱」文件夹（默认 `~/Downloads`，可改）；点「认领新下载」批量处理：
   - 匹配：① 文件名／PDF 元数据里的 DOI 命中队列或全库；② 标题相似度 ≥0.85 命中；③ 匹配不上 → 「待认领」列表，一键指派（复用记录／文件选择器）；
   - 动作：复制进目标目录（同命名规范）→ 登记文件记录 → 挂链（性质 `manual-upload`）→ 队列条目自动销项。

## 六、WebUI 交互

- **入口**：「文件 ▾」菜单新增「**批量下载原文…**」；「获取」标签页承载队列（常驻）；
- **下载对话框三步**：① 范围与选项（**仅缺本地文件**（默认）／全部／选中；目标目录；下载后解析（默认关）；跳过已存在）② 解析中（进度＋实时统计：可直接下载 k／需人工 m／无 OA n）③ 审阅与执行（默认勾选"可直接下载"→[开始下载 N 条]→逐条结果与汇总报告，失败给原因；[导出待获取清单 CSV]）。

## 七、实施切片（按序）

1. **切片一·下载核心（＋驱动界面）**：解析器＋下载核心（校验／原子落地／限速／去重／日志）＋服务端后台任务＋三步对话框＋自动登记挂链；单测（本地假 HTTP＋真 PDF 样张）＋真机小样（10 条逐条核对）。如嫌大，可拆 1a 核心／1b 界面两步交付，顺序不变。
2. **切片二·待获取队列**：旁车存储＋「获取」标签页＋渠道分流与导出。
3. **切片三·下载认领**：收件箱扫描＋自动匹配＋归位挂链＋销项。

## 八、定案项与待办

- 目标目录默认规则、下载后解析默认关、性质名 `auto-download`（下载器）／`manual-upload`（认领）——按本方案默认执行，主笔可改；
- 可选增强：`.env` 加 `PRIMER_UNPAYWALL_EMAIL` 启用 Unpaywall 解析（OA 召回率更高）；
- 边界复述：不集成任何绕过付费墙／反抓取的功能或人工过墙方案。
