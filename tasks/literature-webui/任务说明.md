# 任务说明：文献库 WebUI（primer.literature）

> 状态：待评审（2026-10-05 起草，同日修订）。

## 背景

`primer.literature` 现管"本地 PDF 语料 → 编目 → MinerU 转 markdown"的批处理；检索、获取与分析能力正在扩展。本任务补的是它的**前端**：一个**本地文献库 WebUI**——以本地文件系统为后端，以单个 JSON 文件为库，提供按项目树的文献清单浏览与维护。

## 目标（本期）

1. 启动加载 JSON 库文件；默认当前位置 `./primer.literature.json`，缺失时引导**新建或指定**（流程见《设计规格.md》§6）。
2. 三栏界面：项目树｜文献清单（过滤/搜索/排序）｜记录详情（多文件、各自维护本地文件性质）。
3. 重扫：校验每个本地文件的存在性并在界面标记（不自动修改库文件）。
4. 纯本地运行：仅绑定 `127.0.0.1`，服务不发起外网请求，零新增第三方依赖（stdlib＋现有依赖）。

## 已确认需求口径（2026-10-05，提出方确认）

- 一笔记录**可属于多个项目**；
- 本地文件性质枚举：与 DOI 一致／预印本替代／人工上传／其他（"无文件"是状态，不是性质）；
- 一笔记录**允许多个文件**，**每个文件单独维护性质属性**；
- 技术形态跟随 `primer.review.server` 的"本地服务＋静态前端"先例：纯本地，不依赖外网；
- **项目维度在界面只读**：不新建／重命名／删除项目，也不在界面改写记录归属；变更直接编辑 JSON 文件；
- 端口：默认 8801；被占用时自动改用随机空闲端口并在命令行打印实际端口。

## 交付物

- 代码：数据层、项目树、本地服务与 JSON API、静态前端（布局见《设计规格.md》§7）；
- 测试：pytest，覆盖数据层／项目树／API／首启流程；不访问网络、不启动真实浏览器；
- 文档：`docs/guides/literature_webui.md`；
- 命令行：`python -m primer.literature web`（新增 `web` 子命令，不新增 console script）。

## 范围外（本期不做）

- 云端同步、多用户与权限；
- 全文检索、PDF 内容预览；
- DOI 元数据在线抓取（外网）、自动补全；
- 界面内对项目结构的编辑（新建／重命名／删除、批量改归属）；
- 对被引用文献文件本身的移动、改名、删除。
