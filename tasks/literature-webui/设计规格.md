## 二、布局与交互

### 2.1 五区

| 区域 | 内容 | 要点 |
| --- | --- | --- |
| 顶栏 | 文件、编辑、项目、**显示**四菜单（显示：排序／筛选／重置）；库文件路径常显；全局搜索；`[+ 新建记录]`；`[重扫]` | 路径相对显示，悬停显示绝对路径 |
| 左栏 | 项目树：多项目挂载；父节点计数＝子树**去重**记录数；「未归项目」收纳无项目记录；**空项目**（「项目」菜单里新建、尚未挂记录）也显示，计数 0 | 节点可折叠；项目由「项目」菜单维护 |
| 中栏 | **文献／文件两个标签页**（默认「文献」）。文献页＝当前节点（含子孙）的清单；列＝标题／作者／年／类型／本地文件／DOI。文件页＝本地文件记录清单；列＝名称／格式／大小／状态／关联文献／重复／Markdown | 文献页「本地文件」列＝文件覆盖（**记录自带文件＋已关联的本地文件记录**；前者经重扫校验、后者源文件存在性随文件接口实时校验）：`✓ 2`＝2 个全部存在，`1/2`＝部分缺失，`✗ N`＝全缺失，`—`＝无文件；文件页状态＝待解析／解析中／已完成／失败；文件页「关联文献」列＝该文件挂到的文献记录标题（未关联 `—`） |
| 右栏 | 记录详情：标准字段、DOI、UUID、文件列表（逐项性质徽章）、**关联文件区（关联到的本地文件记录：性质徽章＋解析状态＋逐条解除）**、项目列表（全部挂载；**维护见「项目」菜单**）、操作按钮（含 **「关联文件…」**） | 性质徽章：`[正式]/[预印本]/[题名匹配]/[人工]/[其他]`（见 §3.4）；多选时显示「已选 N 条」摘要；文件页时显示文件详情（含「关联文献」行与关联／解除按钮） |
| 底栏 | 总量／当前显示／文件覆盖统计／库文件／最近重扫时间 | 重扫只更新显示，不改库文件 |

| --- | --- |

| 单击行 | 单选该行，右栏显示详情 |
| Ctrl／Cmd＋单击行 | 加选／取消选择；Shift＋单击行＝自锚点连选一段 |

| 文件菜单 | 打开…＝切换库（编辑器开着先确认）；保存＝立即落盘；另存为…＝写新文件并切换为当前库；导入…＝选本地 CSV／JSON／BibTeX／Markdown，解析后按映射确认合并（库格式直接合并；uuid 冲突自动重分配，缺标题行跳过；对话框内可「AI 重新解析」「联网比对」）；**扫描文件夹…＝弹系统选择框选文件夹，递归收集支持格式（pdf／png／jpg／jpeg／webp）登记为文件记录并自动开始 MinerU 解析；添加本地文件…＝弹系统选择框多选文件（同样自动解析）。登记时按绝对路径＋内容 MD5 查重：路径重复静默跳过；内容重复不登记并在提示里点名"哪份=哪份"**；**自动关联…＝「文件 × 文献」批量匹配（本地进行：标识符／题名／包容判定；不改库；可勾选「联网增强」——对本地未命中的文件按 DOI／题名查学术引擎链再比一轮，升级结果按「存疑」呈现、人工勾选后挂链）；完成后在对话框里预览提案（确定／建议／存疑三档，逐条可勾选／换选／忽略），点「应用选中关联」才落链；同一对话框内附「缺文清单」＝尚未找到本地文件的文献记录（可复制 TSV／导出 CSV）**；**批量下载原文…＝按范围（仅缺本地文件／全部／选中）批量生成下载计划并逐条下载：① 选项（范围＋目标目录＋可选「下载后自动 MinerU 解析」）② 计划预览（可下载／需人工／无 OA 三级、逐条勾选）③ 结果报告（成功／需人工／失败／跳过）。解析链＝`eprint`／arXiv 链接归一 → 记录既有下载链接 → 现场引擎补查；只取合法 OA 直链，doi.org 落地页归「需人工」；下载件内容级校验（`%PDF`＋`%%EOF`＋pdfinfo），坏件不落盘；成功件自动登记为文件记录并挂链（性质 `auto-download`、状态 `downloaded`）**；导出…＝写拷贝（可选仅当前清单；不切换库） |
| 文件页 | 切到「文件」标签页后：单击行＝右栏显示文件详情（**关联文献（可点击跳转选中该记录）**／路径／大小／MD5／DOI／arXiv／状态／Markdown 产物／错误／「疑似重复」清单），操作按钮＝打开文件／打开 Markdown（未解析时置灰）／**关联文献…（弹选择对话框）／解除关联**／重新解析／移除记录（只删记录，不动磁盘文件与产物）；「疑似重复」里命中文献记录的候选附**「关联此文献」**一键挂链；列表「关联文献」列＝挂到的记录标题（未关联 `—`）；列表「重复」列显示 ⚠ DOI／arXiv（悬停查看与谁重复）；有解析任务时每 2 秒自动刷新 |
| 编辑菜单 | 联网查询＝选中记录经引擎链（OpenAlex → NASA ADS → Crossref；前者不通或未命中自动落后者；ADS 需在 `.env` 配 `PRIMER_NASA_ADS_API_KEY`，未配则跳过）置信匹配补全／修正字段；AI 解析＝选中记录交 LLM 校订字段；**两者均为两阶段**——先只计算变更（不动记录），弹「变更预览」（逐条列出 字段：旧值 → 新值），点「应用」才写入、取消即放弃；编辑字段…＝单条开编辑器／多条开批量编辑（只应用改动过的字段）；**全集联网比对…＝对全部记录（或「仅缺下载链接／仅缺关键字段」子集）批量走引擎链（OpenAlex → NASA ADS → Crossref），补充缺失字段、修正错误字段并探测原文下载链接（OA／arXiv 直链优先，无则 DOI 页）；后台任务＋变更预览，确认后写入**；加入项目…＝把选中记录挂到目标项目（可直接输入新路径，不存在自动创建；已挂的跳过）；删除＝删除选中记录（可多条）；清空…＝清空整个库（双重确认；落盘前留 `.bak`）；后台任务进行中时上述项置灰 |
| 项目菜单 | 新建…＝建顶层项目或某项目下的子项目（可勾选同时挂到当前选中记录；**空项目**的声明存库文件旁的 `<库名>.projects.json`）；加入选中记录＝把清单里选中的记录挂到当前点选的项目（需同时选中项目与记录，一键完成）；移动…＝把选中项目（含子孙）移到顶层或某项目下，所有相关记录的路径**立即同步改写**；重命名…＝只改最后一段，子孙路径随之替换；删除…＝删项目及全部子项目，相关记录的相应路径移除。移动／重命名／删除需先在左栏**点选项目**（无选中置灰）；重名冲突直接拒绝 |
| 显示菜单 | 排序…＝多级排序对话框（字段＋升／降序，可「＋添加排序键」多行；默认年份降序）；筛选…＝多条件对话框（字段＋等于／大于／小于／区间内＋值，可多行，**同时满足（AND）**；值为空的行不生效）；重置＝清空排序／筛选／搜索并回到「全部」，恢复显示全部记录（无可重置内容时置灰）。清单标题在有筛选时标注「筛选 N 项」；原清单上的「排序」下拉已并入此菜单 |

## 三、数据规格（JSON）

### 3.1 文件形态

- 顶层为**记录数组**（按需求）。文献记录不带判别字段；**本地文件记录**是数组里 `kind="file"` 的条目（见 §3.2 末），两类可混合共存。
- 默认路径：启动目录 `./primer.literature.json`；可由 `--db` 或首启页指定。
- UTF-8、缩进 2 空格、不转义中文。
- 写回：临时文件＋原子替换；替换前留一份 `.bak`。
- **未知字段保留**：读写往返不丢字段（前向兼容）。
- 库级元数据（版本号等）本期不放进文件；将来如需，另立伴生文件或迁移为对象形态（迁移时保持对数组形态的读取兼容）。
- **项目声明旁车文件**：`<库名>.projects.json`（如 `bibliotheca.projects.json`），内容 `{"projects": ["路径", …]}`，只记录"暂无记录的空项目"与手工声明；缺失时视为空（此时项目集合纯由记录派生），服务在项目菜单操作时自动维护。
- **解析产物**：文件记录的 MinerU 输出解包到库文件旁的 `parsed/<主干名>/`（`markdown.md` ＋ `images/`；`model_output.json` 丢弃）；`md_path` 相对库目录存储；解析中途的 zip 暂存于 `parsed/_zips/` 并在解包后删除。

### 3.2 记录结构

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `uuid` | string | ● | UUID v4；新建时服务端生成；全库唯一 |
| `type` | string | | 文献类型；建议取值：`journal-article`／`conference-paper`／`book-chapter`／`standard`／`report`／`preprint`／`book`／`thesis`／`patent`／`other`；允许自定义 |
| `title` | string | ● | 标题 |
| `authors` | string[] | | 作者（"姓, 名"或原文） |
| `year` | int \| null | | 出版年份 |
| `venue` | string | | 来源（期刊名／文集名／出版社） |
| `doi` | string \| null | | 不带 URL 前缀：`10.1590/jatm.v14.1271` |
| `editor`／`translator` | string[] | | 编者／译者（规则同 `authors`） |
| `volume`／`number`／`pages`／`eid` | string | | 卷／期号（或编号）／页码（`977-980`）／文章号 |
| `publisher`／`location` | string | | 出版者／出版地（biblatex 规范名，`address` 为其旧名） |
| `institution`／`organization` | string | | 机构（授予单位／报告机构）／会议主办单位 |
| `series`／`edition`／`isbn`／`issn` | string | | 丛书／版次／ISBN／ISSN |
| `url`／`eprint` | string | | 链接／arXiv 编号 |
| `download_url` | string | | **原文下载链接**（「全集联网比对」探测：OA／arXiv 直链优先，无则 DOI 页） |
| `eventtitle`／`eventdate` | string | | 会议名称／会议日期 |
| `keywords` | string | | 关键词（分号分隔） |
| `files` | array | | 本地文件列表，每项见下 |
| `projects` | string[] | | 项目路径字符串，`/` 分层层级；**界面只读**，由人工编辑 JSON 维护 |
| `notes` | string | | 多行文本；约定每行一个键值对 `键：值`，导入时自动追加 `原始记录：…` |
| `created_at`／`updated_at` | string | | ISO 8601 带时区 |

`editor` 起的书目字段采用 **biblatex 规范名**；**空值不落盘**（序列化时省略，读入时缺省为空）。编辑器按 `type` 显示对应字段（另可勾选「显示全部字段」）。

`files[]` 每项：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `path` | string | 相对**库文件所在目录**的路径（可移植）；允许绝对路径（原样保留） |
| `nature` | string | `doi-consistent`／`preprint-substitute`／`title-match`／`auto-download`／`manual-upload`／`other` |
| `note` | string | 可选 |

**本地文件记录**（`kind="file"`，与文献记录同数组共存；由「文件」菜单的扫描／添加产生）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `kind` | string | 恒为 `"file"`（判别字段） |
| `uuid` | string | UUID v4；文件记录之间唯一 |
| `path` | string | 源文件路径：库目录内→相对；库外→绝对（原样保留） |
| `name` | string | 文件名（含扩展名） |
| `size` | int | 登记时的字节数 |
| `md5` | string | 文件内容 MD5（登记时计算；读不动时省略） |
| `status` | string | `pending`／`parsing`／`done`／`failed`／`downloaded`（自动下载成功、尚未解析） |
| `md_path` | string | 解析产物 markdown 的相对路径（未解析时省略） |
| `doi`／`eprint` | string | 解析后从 markdown 提取的 DOI／arXiv 编号（取第一个；无则省略） |
| `record_uuid` | string | 关联的文献记录 uuid；未关联时省略（一个文件至多属于一条文献） |
| `nature` | string | 关联性质：`doi-consistent`／`preprint-substitute`／`title-match`／`auto-download`／`manual-upload`／`other`；仅 `record_uuid` 非空时有值 |
| `note` | string | 关联备注，可选 |
| `dup` | object | 语义重复标记：`{kind: "doi"｜"eprint", value, matches: [{kind: "record"｜"file", uuid, label}]}`；无重复时省略 |
| `error` | string | 失败原因（仅 `failed` 时写入） |
| `added_at`／`updated_at` | string | ISO 8601 |

解析由后台队列完成：`PARSE_WORKERS`（2）路并发、每路单次批量最多 `PARSE_BATCH_SIZE`（4）份调用本机 `mineru-kit`（档位 `standard`）——批量省去每份的进程启动与模型加载开销；批量遇错中止时缺产物者逐文件单独重跑（失败隔离）。worker 无活可干时经**退场握手**退出（二次查活与退场承诺在同一临界区），不会漏领退场窗口内新登记的文件；服务重启时遗留的 `pending`／`parsing` 会继续排队（崩溃恢复）。

**查重与自动关联**：*登记时*按绝对路径与**内容 MD5** 双重查重——路径重复静默跳过（`skipped`）；内容重复（命中已有记录或本批先登记者）不登记、回报 `duplicates`（`{"path", "same_as"}`）。*解析完成后*按 **DOI（优先）／arXiv** 与库中记录比对：唯一命中 → **自动挂链**（DOI → `doi-consistent`；arXiv → `preprint-substitute`，候选限 `preprint` 类型或无 DOI 的记录）；候选多个、arXiv 只命中已发表记录、或只能与未关联文件比对 → 不挂链，写入 `dup` 标记待人工确认。已关联文件重解析只刷新标识、**不动链接**；删除文献记录（单条／多条／清空）→ 关联自动解除，指向它的 `dup` 候选一并剪除；导入合并遇 uuid 重分配 → 文件记录的 `record_uuid` 随映射改写。

### 3.4 文件性质枚举（界面徽章）

| 键 | 徽章 | 含义 |
| --- | --- | --- |
| `doi-consistent` | `[正式]` | 与 DOI 指向的版本一致 |
| `preprint-substitute` | `[预印本]` | 用预印本替代正式版 |
| `title-match` | `[题名匹配]` | 由「自动关联」按题名匹配挂链（人工确认后写入） |
| `auto-download` | `[自动下载]` | 由「批量下载原文」自动获取的合法 OA 原文（未解析时状态为 `downloaded`） |
| `manual-upload` | `[人工]` | 人工上传（无 DOI 或暂无正式版） |
| `other` | `[其他]` | 其他情形 |

"无文件"是状态（`files` 为空），不是性质。

## 四、项目树规则

1. 拆分：`path.split("/")`；忽略空段与首尾空白；大小写敏感；层级任意深。
2. 节点计数：子树内**去重记录数**（同一记录挂多个兄弟分支时，父节点只计一次）。
3. 多挂载：记录的多个 `projects` 分别挂载，各路径下均可见。
4. 「未归项目」：`projects` 为空／缺失的记录集中展示。
5. 「全部」：全库记录数。
6. **项目维护（「项目」菜单）**：新建／移动／重命名／删除都在界面完成——项目声明写库文件旁的 `<库名>.projects.json`（支持"暂无记录的空项目"）；移动／重命名／删除会**同步改写所有相关记录的 `projects` 路径**（含子孙），保存即落盘。冲突（重名、移入自身子孙）直接拒绝。逐条记录的归属仍不在编辑器里改（走「项目」菜单或直接编辑 JSON）。

## 五、服务与 API

### 5.1 技术形态

- 纯本地：绑定 `127.0.0.1`；前端零第三方 CDN，静态资源随包。服务默认不发起外网请求——唯一例外是用户主动触发的「AI 重新解析」（调用所配置的 LLM 端点）与「联网比对」（访问 OpenAlex 公共 API）。
- 零新增依赖：stdlib `http.server.ThreadingHTTPServer`（沿用 `primer.review.server` 先例）。
- 端口：默认 8801（`--port` 覆盖）；**被占用时自动改用随机空闲端口，并在 stdout 打印实际端口**；`--no-open` 关闭自动开浏览器。
- 启动：`python -m primer.literature web [--db PATH] [--port N] [--no-open] [--env-file FILE]`。
- 密钥：启动前自动加载 `.env`（`--env-file` 显式指定 > `./.env` > primer 源码仓库根 `.env`）；只注入尚未设置的变量（真实环境优先），报告只含变量名与未识别行数，任何值不打印。

写入类失败返回 `{error, message}`；`message` 英文。LLM 精析的聊天角色按
`literature` → `extract` → `select` 取第一个已定义者——工程根按**库文件所在目录链**
与启动目录自动定位（找 `<工程根>/_primer/config.yaml`），密钥只从环境变量读；
**DOI 只允许逐字取自条目原文**，模型给别的值一律丢弃。联网比对（`/api/import/verify`
的导入比对与 `/api/records/enrich` 的 `verify` 模式）走**同一条引擎链**——
OpenAlex（先走公共池；被限流（HTTP 429）时自动回落 `.env` 里
`PRIMER_OPENALEX_API_KEY` 的个人额度重试）→ NASA ADS（需 `.env` 里
`PRIMER_NASA_ADS_API_KEY`，未配则跳过）→ Crossref，前者不通或未命中自动落后者，
DOI 由引擎给出，与精析共用进度轮询与提交纪律；`ai` 模式的 DOI 只认记录自身
文本（含备注）里的字面量。两条路径
回填的字段同为 §3.2 的书目字段集合（含卷／期／页等 biblatex 字段）；联网路径并探测 `download_url` 原文下载链接（OA／arXiv 直链优先，无则 DOI 页）。

### 5.3 边界

- 服务只读写**库文件本身**；不移动、不修改被引用的文献文件（打开＝只读动作）。
- `/api/open` 拒绝库外或未登记路径。
- 库文件位置不强制 `_primer/`，由用户决定（本库是用户资产，不是 primer 产物）。

## 六、启动流程

1. `--db` 指定：存在→加载；不存在→首启页询问是否新建。
2. 未指定：查 `./primer.literature.json`；存在→加载；不存在→首启页（见线框二）。
3. 首启页：默认路径已填；「新建」→ 写 `[]` 并进入主界面；「打开」→ 校验 JSON 后加载。
4. 打开失败（非法 JSON／无权限）：首启页给出可操作错误（含解析错误位置）。
5. 浏览器自动打开 `http://127.0.0.1:<port>/`；stdout 打印中文启动报告（库路径／记录数／实际端口；端口被占用时注明已回退随机端口）。

## 八、错误处理

- 库文件缺失／非法／无权限：stdout 中文报告、stderr 英文诊断；界面给可操作提示。
- 记录校验失败（缺 `title`、`uuid` 冲突）：拒绝保存并返回字段名。
- 并发写：单进程串行；保存前比对 `updated_at`，不符则提示"库已被外部修改"。
- 重扫不写库；删除记录只改库文件。

## 九、已决与移除

- 端口：默认 8801；被占用时自动改用随机空闲端口并在 stdout 打印实际端口（已定，验收 A13）。
- `tags`：本期从 schema 移除（无此需求；将来如需，因"未知字段保留"可无痛加回，见 §3.1）。
- 项目维度：界面只读——不新建／重命名／删除项目，也不在界面改写记录归属；变更直接编辑 JSON 文件。
