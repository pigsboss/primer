# 验收清单：文献库 WebUI（primer.literature）

> 判定方式：`pytest` 全绿 ＋ 逐项人工／脚本确认；状态列交付时填写。
> 交付时附《交付说明.md》。

## A 功能项

| 编号 | 验收项 | 判定 |
| --- | --- | --- |
| A1 | 首启流程：无默认库时进入首启页；「新建」生成内容为 `[]` 的合法文件并进入主界面；「打开」可加载既有库 | 手工 |
| A2 | 非法 JSON：给出可操作错误（含位置提示），进程不崩溃 | 手工＋单测 |
| A3 | 数据层往返无损；**未知字段保留**；写回＝原子替换＋`.bak` | 单测 |
| A4 | 新建记录自动补 `uuid`（v4）且全库唯一；重复 uuid 被拒绝 | 单测 |
| A5 | 项目树：`/` 分层；**多挂载**记录出现在每个所属路径；父节点计数按去重记录数 | 单测＋手工 |
| A6 | 「未归项目」收纳无项目记录；「全部」＝全库计数 | 单测＋手工 |
| A7 | 清单：按节点过滤（含子孙）；搜索标题／作者／DOI／项目路径；按年份／标题排序 | 手工 |
| A8 | 详情：多文件逐项性质徽章；多项目**只读**列出；编辑书目与文件字段保存后库文件正确更新；项目字段在界面不可编辑 | 手工 |
| A9 | 重扫：缺失文件在列表与详情标记；库文件不被自动修改 | 手工 |
| A10 | `/api/open` 仅允许库中登记路径；未登记／库外路径被拒绝 | 单测＋手工 |
| A11 | 纯本地：静态资源无外链（无 CDN／无外域 script/link/img，`doi.org` 跳转除外）；服务仅绑定 `127.0.0.1`；`pyproject.toml` 依赖零新增 | 脚本 |
| A12 | 语言纪律抽查：界面文案与 stdout 报告中文；JSON 键／选项名／异常消息英文 | 人工 |
| A13 | 端口：8801 被占用时改用随机空闲端口并在 stdout 打印实际端口；`--port` 显式指定的端口占用时同样回退 | 脚本＋手工 |
| A14 | 文件菜单：打开／保存／另存为／导出均可用；另存为切换当前库、导出不切换；错误（目标已存在、非法 JSON、无库）均有可读提示 | 手工＋单测 |
| A15 | 导入（文件选择器）：选 CSV／JSON／BibTeX／Markdown → 解析预览 → 列映射确认 → 合并；库格式 JSON 直接合并；Markdown 支持参考文献清单（`[n]` 条目＋`［原文：…］` 尾标）与管道表格两种形态；uuid 冲突自动重分配、缺标题行跳过并计数；不支持／空／非法文件有可读提示 | 手工＋单测 |
| A16 | LLM 精析（导入对话框「AI 重新解析」）：范围可选 疑似／全部；后台线程进度轮询；完成后刷新列、样本与建议映射；DOI 防幻觉（只认原文出现过的字面量）；块失败保留原行；角色未配置／缺密钥给出可操作错误；精析期间不可提交 | 单测＋手工 |
| A17 | 编辑菜单：删除＝删除当前选中记录（无选中置灰）；清空＝双重确认后清空整个库（落盘前 `.bak`）；两者完成后列表与状态栏即时刷新 | 手工＋单测 |
