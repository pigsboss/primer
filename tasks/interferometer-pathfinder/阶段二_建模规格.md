# 阶段二建模规格：合束器（Combiner）

依据：refs/ 内三张合束器特写及组合体渲染图。凡与集光器共用的构件（平台舱、太阳翼、散热器、材质），以 collector.py 为准，本文件只写差异项。

## 一、总体构成

```
          ┌──────────┐
          │ 顶部机构簇 │  ← 接收折转镜×2（朝向两侧集光器）＋敏感器 1–2 台
          ├──────────┤
          │ 深色圆柱   │  ← 载荷舱（收光合束舱），比集光器镜筒矮、细
          │  载荷舱    │
┌─────────┴───────────┴─────────┐
│      金色方形平台舱（同集光器）    │
│   侧面白色胶囊散热器（同形制）     │
└────────┬───────────────┬──────┘
      太阳翼              太阳翼
```

## 二、构件逐项规格（差异项）

### 1. 平台舱

- 与集光器平台舱同尺寸、同材质（读 collector.py 常量）；允许高度微调（±0.1 m）以容纳合束光学，但宽高一致。

### 2. 载荷舱（`module`）

- 深灰近黑**圆柱舱**，立于舱顶中央（居中，不偏向——组合体状态下两集光器镜筒分居其两侧）；
- 外径 ≈ 舱宽的 0.35–0.45 倍（明显细于集光器镜筒的 0.5 倍）；
- 高出舱顶 ≈ 舱高的 0.5–0.8 倍（明显矮于集光器镜筒）；
- 顶端开口或加盖均可（渲染图为平顶），侧壁下部可有小型收光窗口凸台（对应两路光束水平入射）。

### 3. 顶部机构簇（`recv_01`、`recv_02`，可加 `aux_01`）

- 接收折转镜装置 2 台：坐在**载荷舱顶面**上，分别朝向 ±X（两侧集光器方向）；形制为"底座＋斜置镜筒/棱镜座"，体量约为载荷舱外径的 1/3；
- 敏感器 1–2 台（`aux_01`）：更小的柱状/方块件，散布载荷舱顶面或舱顶面；
- 组合体顶部特写中可见 4–5 台机构，分布式特写中可见 2–3 台——取 3 台（2 收光＋1 敏感）。

### 4. 散热器

- 与集光器同形制（白色胶囊长条），舱体侧面 2 根；分布式正视图中舱顶面后方还可见 1 根，可选做。

### 5. 太阳翼

- 与集光器同形制同尺寸，±X 展开。

## 三、命名约定（verify_combiner.py 依赖）

| 对象名 | 构件 |
|---|---|
| `bus` | 平台舱 |
| `module` | 载荷舱 |
| `recv_01`、`recv_02` | 接收折转镜装置（朝向 ±X） |
| `aux_01`（可选 `aux_02`） | 敏感器 |
| `radiator_01`、`radiator_02` | 散热器 |
| `panel_X1`、`panel_X2`、`panel_-X1`、`panel_-X2` | 太阳翼四板 |

combiner.py 须提供 `build()`；直接运行时依次 `build()` ＋ 渲染 side/front/iso/top 四视角到 `out/combiner/`。

## 四、比例校验关系（目估，供 verify）

1. 载荷舱外径 / 舱宽 ∈ [0.35, 0.50]；
2. 载荷舱高出舱顶 / 舱高 ∈ [0.5, 0.9]；
3. 载荷舱高度 < 集光器镜筒高度（读 collector.py 常量核对）；
4. 太阳翼展开总宽 / 舱宽 ∈ [3.0, 4.5]（同集光器）。

## 五、明确不做的事

- 不做载荷舱内部合束光学（延迟线、消零光路、探测器）；
- 不做星光/器间光束；
- 不做组合体装配（阶段三）。
