# 阶段三 建模规格：三器组合体（在轨组合体测试状态）

依据：论证 PPT 第 51 页（"发射状态下为合束器、集光器三器组合体构型，2 个集光器与合束器承力筒相连"）、第 56 页（"组合体状态下，以 ~2.5 m 定长基线开展干涉探测"）、第 57 页（"3 个探测器共机架安装"），以及 refs/ 组合体渲染图、`refs/frames/opt_f121.png`。

**状态定义**：本阶段做的是**组合体在轨测试状态**——三器共机架、太阳翼展开。发射收拢状态（太阳翼平贴、装整流罩）本阶段不做。《任务说明》里"两状态"指组合体状态与分布式状态，不是收拢/展开。

## 一、布局（共机架两级堆叠）

```
        +Z（星光入射方向）
 ┌─镜筒B─┐  ┌─载荷舱─┐  ┌─镜筒A─┐
 │集光器B│  │(合束器) │  │集光器A│      ← 上层甲板：集光器B｜载荷舱｜集光器A
 └──────┴──────┬──────┴──────┘
        │  共机架（金色平台）  │           ← 下层：共机架（金色 MLI 包覆）
        │  合束器平台舱（居中） │           ← 合束器平台舱紧贴共机架下方中央
        └──────────┬──────────┘
             太阳翼 ±X（三器均展开）
```

1. **基线**：两镜筒轴线（Y 向）距离 = 2.366–2.5 m。PPT 文字"~2.5 m 定长基线"是权威值；按包络反算的 2.366 m 可接受。验收判据 ∈ [2.3, 2.6] m。
2. **共机架（deck）**：金色箱体，Y 向长 ≈ 基线＋集光器舱长边（≈3.5 m），X 向宽 ≈ 1.2 m，Z 向厚 0.3–0.5 m。顶面即上层甲板。渲染图中下层那个"大金箱"就是它（合束器平台舱与共机架一体）。
3. **合束器平台舱**：居中，舱顶与共机架底面贴合（或嵌入共机架内）。
4. **合束器载荷舱**：位于**上层甲板中央**（|y| ≤ 0.3 m，|x| ≤ 0.15 m），底面与甲板贴合，顶面与集光器舱顶面高差 ≤ 0.3 m——顶视呈"镜筒—载荷舱—镜筒"一排（对照 `组合体_顶部特写.png`）。载荷舱经承力筒与下方平台舱相连，连接段藏在共机架内。
5. **两台集光器**：复用单体 `build()`，置于 y = ±基线/2，舱底与甲板贴合（不悬空、不嵌入超过 0.05 m）；储箱与出光窗口朝内（朝合束器），与单体"朝相邻器"规则一致。

## 二、太阳翼

- 三器均按**单体分布式构型展开**（±X 两翼、弦向竖立），**不收拢、不平贴**。
- 组合体渲染图只画左右各一翼，是概念图的简化表达，不按它收翼；三器在轨均需供电，全部展开才是物理自洽的状态。

## 三、结构外观（本次返工的硬约束）

- 共机架、承力筒及一切连接结构**一律金色 MLI 包覆**（R>G>B）。
- 场景中除镜筒、载荷舱、机构簇、太阳翼外，**不得出现深灰/黑色独立梁体**。现行版那根横跨两集光器空档的外露深灰转接梁，是本次打回的首要原因——参考图里没有任何外露结构，所有连接都藏在金色包覆之内。

## 四、储箱

- 白色胶囊形推进剂储箱（单体规格 §二.4 已改名）。
- 集光器两只：朝内（y 坐标符号与所属舱相反）。
- 合束器/共机架两只：在下层 ±X 侧面外露（对照 `组合体_整体渲染.png` 下层舱侧面的两根白罐）。

## 五、包络（记录项）

输出三器舱体外缘 max|y|（应 ≤1.85 m，对应 Φ3650 整流罩）与组合体总高（应 ≤4.61 m），作为日志记录并判定。

## 六、明确不做

- 不做发射收拢状态（太阳翼平贴）；
- 不做粉色入射光束、红色器间光束（阶段四）；
- 不做分离动画（阶段四）。
