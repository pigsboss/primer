# 阶段三 建模规格：三器组合体（在轨组合体测试状态）

依据：论证 PPT 第 51 页（"2 个集光器与合束器承力筒相连"）、第 56 页（"~2.5 m 定长基线"）、第 57 页（"3 个探测器共机架安装"），以及 refs/ 组合体渲染图与 `refs/frames/opt_f040.png`。

## 一、布局（两层）

```
        ┌镜筒B┐  ┌载荷舱┐  ┌镜筒A┐     ← 上层：集光器B｜合束器载荷舱｜集光器A（同层成排）
        └──┬──┘  └──┬──┘  └──┬──┘
   ┌──────┴──────── 合束器平台舱（金色大箱，与共机架一体）────────┴──────┐   ← 下层：仅此一层
   │                    太阳翼（±X 展开，仅合束器一副）                     │
```

1. **基线**：两镜筒轴线（Y 向）距离 = 2.366–2.5 m。PPT"~2.5 m 定长基线"是权威值；按包络反算的 2.366 m 可接受。判据 ∈ [2.3, 2.6] m。
2. **合束器平台舱（＝共机架本体，下层唯一实体）**：金色箱体，Y 向长 ≈ 基线＋集光器舱长边（≈3.5–3.6 m），X 向宽 ≈ 1.2 m，Z 向厚 0.3–0.5 m。**两台集光器舱底直接落在它顶面上**，器与箱之间不得有任何独立平板或梁件；连接段（法兰/承力筒）收于金色 MLI 包覆之内。
3. **合束器载荷舱**：位于平台舱**顶面中央**（|y| ≤ 0.3 m，|x| ≤ 0.15 m），底面与顶面贴合，顶面与集光器舱顶面高差 ≤ 0.3 m——顶视呈"镜筒—载荷舱—镜筒"一排（对照 `组合体_顶部特写.png`）。
4. **平台舱顶面上方除两集光器与载荷舱外不得有任何对象。**
5. **两台集光器**：复用单体 `build()`，置于 y = ±基线/2，舱底与平台舱顶面贴合（不悬空、不嵌入超过 0.05 m）；储箱与出光窗口朝内（朝合束器），与单体"朝相邻器"规则一致。

## 二、太阳翼

- **集光器：折叠平贴**各自舱体 ±X 侧面（保留单体翼面的板格与蓝色材质，仅改姿态）。依据 `refs/frames/opt_f040.png` 正视图：集光器高度上**没有**伸出的翼片，舱侧为平贴舱壁的电池阵面。
- **合束器：保持单体展开构型**（±X 两翼、弦向竖立）——组合体中真正展开的大翼只有这一副。
- 不允许为折叠翼新建深灰/黑色机构件；若需铰链/收纳件示意，一律金色并计入包络。

## 三、结构外观

- 平台舱、承力筒及一切连接结构**一律金色 MLI 包覆**（R>G>B）。
- 场景中除镜筒、载荷舱、机构簇、太阳翼、储箱、出光窗口外，**不得出现深灰/黑色独立结构件**，也不得有独立 deck/beam/truss/plate 类对象。

## 四、储箱

- 白色胶囊形推进剂储箱。
- 集光器两只：朝内（相对舱心偏移指向合束器）。
- 合束器/平台舱两只：在 ±X 侧面外露。

## 五、包络（记录项）

输出三器舱体外缘 max|y|（应 ≤1.85 m，对应 Φ3650 整流罩）与组合体总高（应 ≤4.61 m），作为日志记录并判定。

## 六、明确不做

- 不做粉色星光入射光束、红色器间光束、分离过程动画（阶段四）。
