# 阶段二任务说明：合束器（Combiner）单体建模

## 目标

在阶段一集光器（collector.py）基础上，建立**合束器单体**的静态三维模型，交付 `combiner.py`（Blender Python 脚本，结构要求与 collector.py 相同：`build()` 函数＋直接运行时生成四视角自检渲染到 `out/combiner/`）。

## 与阶段一的关系（重要）

1. **先读 collector.py**：合束器与集光器是同族航天器，平台舱尺寸、金色 MLI 材质、太阳翼形制、散热器形制必须沿用 collector.py 的常量与材质函数，不允许另起一套配色与风格；
2. 合束器**没有镜筒**——它的标志性构件是舱顶中央的深色圆柱载荷舱（收光合束舱），体量明显小于集光器镜筒；
3. 本阶段只做单体；与集光器的组合体装配是阶段三，但建模时舱顶布局要为"两集光器镜筒分立载荷舱两侧"留位（见 refs 组合体渲染图）。

## 验收与迭代

以《阶段二_验收清单.md》＋ `verify_combiner.py` 为准，闭环同阶段一：

```
blender --background --python combiner.py
blender --background --python verify_combiner.py
```

全部 PASS 后按清单目检比对，交付：combiner.py、verify 日志、out/combiner/ 四视角渲染图、≤10 行中文说明（按图还原项与推断项）。
