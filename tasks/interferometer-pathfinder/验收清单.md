# 验收清单与迭代规程：集光器建模（v1.1）

本文件是 kimi code 的**可检验目标**。建模脚本 `collector.py` 完成后，必须按以下规程迭代，直到全部通过为止。
v1.1（2026-10-01，随《验收反馈_07》）：舱体平面尺寸修订（X 长边 0.91／短边 0.59／
Y 宽 0.65／Z 高 0.91 不变），A3/A5 判据联动改写；其余条目不变。

## 迭代闭环（每一轮都做）

```
blender --background --python collector.py        # 生成模型并渲染自检图到 out/
blender --background --python verify.py           # 自动检查，打印 PASS/FAIL 清单
# 然后人工式目检：把 out/ 四张渲染图与 refs/ 主参考图逐张比对
# 有 FAIL 或目检不一致 → 修改 collector.py → 回到第一步
```

**完成判据：verify.py 全部 PASS，且目检比对无"缺件/错件/比例失调"。**

## 一、自动检查项（verify.py）

| # | 检查项 | 判据 |
|---|---|---|
| A1 | 场景对象齐备 | 存在 `bus`、`tube`、`gimbal_01`–`gimbal_03`（至多 04）、`tank_01`、`tank_02`、`panel_X1/X2/-X1/-X2`、`window_out` |
| A2 | 镜筒口径 | `tube` 外径 0.55–0.65 m |
| A3 | 比例①（v1.1 改写） | 镜筒外径 / 舱体 **Y 向宽度**（沿基线，0.65 m）∈ [0.85, 1.0]（"宽度略大于筒直径"） |
| A4 | 比例② | 镜筒顶面高出舱顶 / 舱高 ∈ [0.7, 1.1]（用网格顶点求真实包围盒，不依赖对象原点） |
| A5 | 比例③（v1.1 改绝对值） | 太阳翼四板展开总宽 ∈ [3.6, 5.4] m（翼尺寸不随舱体修订变化） |
| A6 | 材质色 | 舱体金色（R>G>B）、镜筒近黑（RGB 均 <0.1）、储箱乳白（RGB 均 >0.8）、太阳翼深蓝（B>R） |
| A7 | 太阳翼朝向 | 四板分居 ±X 两侧、不沿 Y 偏置；板面竖立（弦向沿 Z，法线 ±Y） |
| A8 | 储箱位置 | 两只胶囊罐贴在舱体 +Y 侧面（长边、朝相邻器），微凸出舱面 |
| A9 | 出光窗口 | 存在 `window_out`，位于镜筒根部侧面，朝向 +Y（朝相邻器，做符号校验） |
| A13 | 平面梯形 | 取 `bus` 顶面顶点按 y 正负分组比较 X 向跨度：短边/长边 ∈ [0.5, 0.8]，且长边在 +Y 侧 |
| A10 | 自检渲染 | `out/` 下生成 side/front/iso/top 四张 PNG，分辨率 ≥800×600 |

## 二、目检比对项（对照 refs/）

1. **对 `集光器特写_斜俯视.png`**：顶部机构簇数量、围绕镜筒根部的布置方式一致；
2. **对 `集光器特写_侧视.png`**：镜筒、舱体、太阳翼三者体量关系一致；
3. **对 `组合体_顶部特写.png`**：散热器白色圆角长条的形态与位置一致；
4. 无多余构件（不要把合束器的中央圆台做到集光器上）。

## 三、迭代优先级

FAIL 项按 A1 → A10 顺序修；目检第 4 条（多做了构件）优先级最高——宁缺毋滥。

## 四、交付定义

- `collector.py`：一键跑通，参数集中在文件头常量区；
- `verify.py` 输出全 PASS 的日志（保存为 `out/verify_log.txt`）；
- `out/` 四张自检渲染图；
- 一段不超过 10 行的中文说明：哪些是按图还原的、哪些是推断的。
