## 一、总体构成（自下而上五层）

```
        ┌─────────────────┐
        │  黑色圆筒镜筒     │  ← 收光望远镜（0.5 m 口径），顶部开口带遮光罩
        │  （星光从顶端入射） │
        └────────┬────────┘
        ┌────────┴────────┐
        │  灰色机构簇       │  ← 3–4 台小型机构，围绕镜筒根部布置
        │ （随动/敏感器）    │

   ±X 两翼，每侧两块串联，弦向竖立
```

## 二、构件逐项规格

### 1. 平台舱（Bus）

- 形状：箱体，**平面为梯形**（平行边沿 X，长边 **0.91 m** 朝 +Y 即朝相邻器，短边 **0.59 m** 朝 −Y；±X 两侧为斜面），MLI 金色多层隔热包覆（表面有轻微褶皱质感）；
- 体量（v1.1 修订【设计方读图裁决，待书面确认】）：**X 向（深，⊥基线）长边 0.91 m／Y 向（宽，∥基线）0.65 m／Z 高 0.91 m**——读法依据：遮光筒为圆柱，舱宽略大于筒直径（筒径 ≈0.6 m＝口径 0.5 m＋壁厚余量）、舱深远大于筒直径、深≈高（提出方 2026-10-01 10:12/10:51）；整器发射包络 ≤Φ3650×4610 mm 为三器共架；整器质量 ≤3.6 t（三器合计，建模不涉及质量）。

### 2. 镜筒（Telescope Tube）

- 黑色哑光圆筒，外径对应 0.5 m 口径（含遮光罩外径目估约 0.55–0.6 m）；
- 高度约为平台舱高度的 0.8–1.0 倍，立于舱顶一侧（非居中——参照特写图，镜筒偏置，给中央合束器舱留位是组合体的事，单体建模时镜筒居中偏一侧均可，以特写图为准）；
- 顶端开口（星光入射口），口部有遮光罩沿；
- **镜筒根部侧向有出光窗口**：收光系统在筒内将光束压缩后，从根部侧向折出射向合束器——单体模型可用一个小的黑色方/圆凸台表示折转镜舱。

### 3. 灰色机构簇（镜筒根部）

- 3–4 台小型灰色机构，围绕镜筒根部布置在舱顶面；
- 单台形状：底座小方块＋上方斜置的圆柱/棱柱（类似两轴转台），尺寸约为镜筒外径的 1/4–1/3；
- 功能（建模注释用）：两轴粗随动装置、星敏感器、激光雷达/视觉敏感器。

### 4. 推进剂储箱

- 白色/乳白色胶囊形长罐（圆角端头），贴在平台舱侧面微凸出舱面；
- 安装方位：**长边所在侧面（+Y，朝相邻器一侧）**；
- 特写图中舱体侧面可见 2 只并列，组合体渲染中下层舱（共机架）±X 侧面亦有 2 只。

### 5. 太阳翼

- 构型：±X 两翼，每侧两块板串联；**板面竖立**（弦向沿 Z，法线 ±Y）；
- 分布式状态与组合体在轨测试状态**均为展开构型**（组合体渲染图只画两翼是概念图简化）；
- 发射收拢状态（平贴 ±X 斜面）后续如需要再单列；
- 电池板：深蓝色/近黑，表面有白色网格线（电池片分隔线），可用材质节点或贴图平面实现；
- 单板尺寸目估：长约 1.5×舱宽，宽约 0.6×舱宽。

## 三、材质与颜色

| 构件 | 颜色 | 材质要点 |
|---|---|---|
| 平台舱 | 金色（MLI 金，偏 #C9A227 一带） | 金属度中低、粗糙度中高，带轻微凹凸模拟褶皱 |
| 镜筒 | 哑光黑 | 低金属度、高粗糙度 |
| 机构簇 | 中灰 | 普通金属/塑料感 |
| 储箱 | 乳白 | 哑光 |
| 太阳翼 | 深蓝近黑＋白网格 | 网格可用线框纹理或凹凸贴图 |
| 入射光束（后续阶段） | 粉色半透明 | 本阶段不做 |

## 四、坐标与比例约定

- 1 Blender 单位 = 1 m；
- +Z 为舱顶方向（镜筒指向 +Z，即星光入射方向）；
- 舱体中心为原点；太阳翼沿 ±X 展开；
- **平台舱平面为梯形**（v1.1 修订）：平行边沿 X，长边 **0.91 m** 在 +Y（朝相邻器一侧），短边 **0.59 m** 在 −Y（组合体中朝外）；Y 向宽度 **0.65 m**；±X 两侧面因此为斜面，太阳翼装在两斜面上；
- 镜筒根部侧向出光窗口朝 **+Y**（朝相邻器/合束器一侧）。

## 五、从参考图目估的比例关系（供校验）

1. 镜筒外径 ≈ 舱体 **Y 向宽度（沿基线）的 0.85–0.95 倍**（v1.1 修订，提出方"宽度略大于筒直径"；旧"≈舱宽 0.45–0.5 倍"的舱宽基准为旧 X 长边，随尺寸修订作废）；
2. 镜筒顶面高出舱顶 ≈ 舱体高度的 0.8–1.0 倍；
3. 机构簇单台高度 ≈ 镜筒外径的 0.3 倍；
4. 太阳翼四板展开总宽 ≈ **4.2–4.8 m（绝对值，v1.1 改记）**——翼尺寸不随舱体平面
   修订变化（能源需求不变【推断】）；与舱体 X 长边之比升为 ≈4.6–5.3，差异记入交付说明；
5. 储箱罐体长度 ≈ 舱侧面高度的 0.7 倍。

## 六、构件命名约定（verify.py 依赖，必须遵守）

| 对象名 | 构件 |
|---|---|
| `bus` | 平台舱 |
| `tube` | 镜筒（含遮光罩，合并为一个对象） |
| `gimbal_01`–`gimbal_03`（至多 `04`） | 机构簇单台 |
| `tank_01`、`tank_02` | 推进剂储箱 |
| `panel_X1`、`panel_X2`、`panel_-X1`、`panel_-X2` | 太阳翼四板 |
| `window_out` | 镜筒根部侧向出光窗口 |

collector.py 须提供 `build()` 函数：调用后在当前场景生成全部对象（供 verify.py 复用）；脚本直接运行时依次执行 `build()` 与四视角渲染。

## 七、明确不做的事

- 不做内部光学（卡氏＋三反镜组）剖视；
- 不做 Stewart 隔振平台细节（渲染图中不可见）；
- 不做合束器、不做组合体装配、不做光束、不做动画（均为后续阶段）。
