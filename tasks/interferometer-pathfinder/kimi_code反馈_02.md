# kimi code 反馈 02：输入记录的有效性复盘（s2ai 视角）

答复对象：阶段四全流程（规格 v1.0→v2.0、反馈 01→07、验收通过）。
**性质**：不是施工报告，是**执行方对"哪些记录真正驱动了建模成功"的实证反馈**——供 s2ai 记录规范、
《建模任务书编写与验收规范》与 kimi work 的任务书模板取用。

**一句话结论**：能驱动 AI 把 Blender 模型一次做对的记录，是**可执行、带口径、带出处、带量法、
可由脚本复算**的记录；其余每一处缺口，我都要自己补一格，而补格就是返工。

**定量证据**：本任务 8 轮迭代；返工三处根因（3.60 m 伪文据、1.24/1.20 遗留值、Z 折拓扑误推广）
**全部**是"术语或数值口径未锁死"；我在各版交付说明里自造"判据读法/差异"条目 **12 条**——
**每条 = 记录里缺的那一格**（清单见 §四.5）。

## 三、给 kimi work 的可照做建议

1. **构型记录六件套**（缺一件我就得补格）：`值`／`口径(axis_convention)`／`出处(provenance)`／
   `量法(measurement)`／`判据(criteria id + expr)`／`不确定度(待确认/工作值)`。
   样例（本任务可直接反推）：
   ```yaml
   component: 集光器.舱板
   axis_convention: {高: +Z沿光轴, 宽: +Y沿集光器-合束器连线, 深: +X垂直高宽}
   value: {深: {long: 0.91, short: 0.59}, 宽: 0.65, 高: 0.91}
   unit: m
   provenance: {type: 设计方裁决, ref: "T8 / 2026-10-01 10:12", literal: "宽度显著小于高度与深度"}
   measurement: 网格顶点包围盒；梯形取两端面半宽线性插值
   criteria: [{id: A3, expr: "筒径/宽 ∈ [0.85,1.0]"}]
   uncertainty: 待设计确认；确认后只允许动常量
   ```
2. **参数单一源**：各阶段规格**引用**参数源，不再各自复述数值（本次漂移证据见 §二）。
3. **教训→硬约束**：把评审教训从反馈文档搬进规格的"硬约束"节，或直接落成一条 E 判据。
4. **素材台账加引用字段**，并在任务书开头列"本任务**必须看图**的清单"（我会逐张核）。
5. **收编我自造的 12 条读法**（回填进《验收清单》，避免下一轮重新发明）：
   ① 翼厚按**逐展向切片局部厚度**（crown 会撑大法向包围盒）；② 板料厚度取**两轴细切片的最小**；
   ③ 缝线"视觉宽度"用解析估计式（带宽/2π·scale·0.25）；④ 周期纹理黑名单**只查 MLI**（板格靠域扭曲去规则化）；
   ⑤ E14"D11 仍通过"以**包络常数**承接；⑥ E10 计入**合束器半宽**；⑦ E13"根部铰链"＝**SADA**；
   ⑧ E21 扫掠**自锁紧机构解除后**起算；⑨ "成线/等距/法向"的容差与量法；⑩ 十字轮廓对边轴/第三边轴的轴归属；
   ⑪ D7 整摞外廓 ≤0.16 m 与 D8 跨度 ≥3×舱宽的**分母取值**；⑫ 判据分母随几何修订时**必须联动**（本次 C2 实例）。
6. **改文件类许可写清边界**（"仅 X 及联动判据"优于"一行不动"）；**每条判据要求实测值回执**。
