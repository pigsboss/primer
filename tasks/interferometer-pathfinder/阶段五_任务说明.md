## 交办指令（2026-10-01，阶段五 v1——kimi code 请执行）

读《阶段五_建模规格.md》（**v1.0**）与《阶段五_验收清单.md》（**v1.0**），在几何 v2
已验收交付基础上执行：

1. **动画脚本 `separation.py`**：import 复用 `assembly.py`／`formation.py`／`wing.py`
   的 build 函数与锁紧机构实现（**禁止复制粘贴**，单体与场景脚本一行不动），按
   S0→S1→S2→S3→S4 五状态生成关键帧动画：
   - S0 组合体锁紧态（＝阶段三验收场景）→ S1 锁紧释放机构解除（机构态切换，
     无相对运动）→ S2 集光器 +Z 直提 ≈2.0 m（翼保持收拢）→ S3 集光器 ±Y 平移至
     y=±6（合束器全程不动）→ S4 集光器十字翼展开（收拢逆序）＋光束淡入 →
     观测态定格（＝阶段四验收场景）；
2. **姿态守恒**：全程三器无滚转/偏航/俯仰，分离纯平移（直提段 x/y 不变、侧移段
   x/z 不变）；分离作动抽象处理（机构态切换＋缓动平移），**不作动机构特写**；
3. **时长参数化**：全程 ≈20 s@24 fps（S1≈1 s／S2≈4 s／S3≈8 s／S4≈5 s／定格 ≈2 s），
   各段帧号集中文件头常量，一处改处处改；
4. **自检脚本 `verify_separation.py`**：按清单 v1.0 跑 **F1–F12**（不得自增删），
   输出 `out/separation/verify_log.txt` 与机器可读 `separation_report.json`；
5. **产物**：`out/separation/` 关键帧定图 ≥6 张（S0／S1／S2 末／S3 中／S3 末／S4 末，
   ≥1200×900，64 samples）＋预览动画（可用低采样或 EEVEE）＋两份记录文件；
   **等审查通过后才允许跑正式档全帧渲染**。
