# 阶段三 验收清单：三器组合体

迭代闭环同前两阶段：`assembly.py` → `verify_assembly.py` → 目检比对。以下 D 判据**取代** kimi code 自编的那一版（D2 保留、其余重写）。

## 一、自动检查项（verify_assembly.py）

| # | 检查项 | 判据 |
|---|---|---|
| D1 | 对象齐备 | 集光器×2（bus/tube/gimbal×3-4/tank×2/panel×4/window_out 各两套，命名空间可 colA_/colB_）、合束器 bus/module/recv≥2/tank×2/panel×4、共机架 `deck` |
| D2 | 基线 | 两 `tube` 轴线 y 坐标之差 ∈ [2.3, 2.6] m（PPT 第 56 页"~2.5 m 定长基线"） |
| D3 | 对称居中 | \|y_tubeA＋y_tubeB\| ≤ 0.1 m；`module` 的 \|y\| ≤ 0.3 m、\|x\| ≤ 0.15 m |
| D4 | 支撑关系 | 两集光器舱底 − deck 顶面 ∈ [−0.05, 0.05] m；`module` 底 − deck 顶面 ∈ [−0.05, 0.05] m；合束器舱顶 − deck 底面 ∈ [−0.05, 0.05] m（不允许任何一台悬空） |
| D5 | 上层同高 | `module` 顶面与集光器舱顶面高差 ≤ 0.3 m（顶视"镜筒—载荷舱—镜筒"同层成排） |
| D6 | 共机架 | `deck` 为金色（R>G>B）；Y 向跨度 ≥ 基线＋0.9 m；两集光器舱底面在 XY 投影上落于 deck 顶面范围内 |
| D7 | 无外露裸结构 | 除 tube/module/gimbal/panel/window_out 外，全部结构件（deck、连接件）基础色为金色；场景中不存在跨两集光器空档的深灰/黑色独立梁体（按材质色判定：非金色结构件数量为 0） |
| D8 | 太阳翼展开 | 三器各 ±X 两翼（每侧两块，板面竖立、弦向沿 Z）；全组合体 X 向总跨度 ≥ 3×舱宽（即**展开**，平贴收拢判 FAIL） |
| D9 | 储箱朝向 | 集光器 tank 的 y 坐标符号与所属舱相反（朝内）；合束器两只 tank 位于 ±X 侧面（\|x\| ≈ 舱半宽 ±0.15 m） |
| D10 | 材质色 | 舱/架金（R>G>B）、筒与载荷舱近黑、储箱乳白（RGB>0.8）、翼蓝（B>R） |
| D11 | 包络记录 | 输出三器舱体外缘 max\|y\| ≤ 1.85 m、组合体总高 ≤ 4.61 m（记录并判定） |
| D12 | 自检渲染 | `out/assembly/` 下 side/front/top/iso 四张 PNG，≥1200×900 |

## 二、目检比对项（对照 refs/）

1. **对 `组合体_整体渲染.png`**：紧凑两级堆叠——下层金色大平台、上层两台集光器分居两侧、载荷舱居中；无外露梁；
2. **对 `组合体_顶部特写.png`**：顶视"镜筒—载荷舱—镜筒"成排，机构簇围绕镜筒根部与载荷舱顶；
3. **对 `refs/frames/opt_f121.png`**（新抽取的动画末帧）：同角度斜俯，三器太阳翼全部展开；
4. 现行版三处目检硬伤必须消除：① 三器一字拉开＋外露转接梁；② 太阳翼收拢平贴；③ 合束器舱吊挂在下层中央、载荷舱顶面远低于集光器舱顶。

## 三、数值冲突处理原则

- **结构关系、构件有无、朝向**——以渲染图为准；
- **尺寸数值**——以 PPT 文字/指标表为准（基线 ~2.5 m 即此例：渲染图把两集光器画成相邻，不按图取 1.3 m，按文字取 2.3–2.6 m）；
- 渲染图之间互相矛盾时（如组合体渲染的太阳翼画法与单体特写不同），以**已经验收的前序阶段**为准。
