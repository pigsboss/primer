## 一、自动检查项（verify_assembly.py，D1–D12）

| # | 检查项 | 判据 |
|---|---|---|
| D1 | 对象齐备且无独立连接件 | 集光器×2（bus/tube/gimbal×3–4/tank×2/window_out 各两套，命名空间可 colA_/colB_）、**合束器平台舱（3.60×1.24×0.90，全高，v1.1 勘误）**、合束器载荷舱齐备；**太阳翼机构件齐备：每翼 SADA 根件×1＋帆板×4＋板间铰链×3**（场景内重建，单体翼板隐藏不计）；场景中不存在任何独立 deck/beam/truss/plate 类对象（按对象名与网格真实包围盒双重判定） |
| D2 | 基线 | 两 `tube` 轴线 y 之差 ∈ [2.3, 2.6] m（PPT 第 56 页"~2.5 m 定长基线"） |
| D3 | 对称居中 | \|y_A＋y_B\| ≤ 0.1 m；`module` 的 \|y\| ≤ 0.3 m、\|x\| ≤ 0.15 m |
| D4 | 两层支撑 | 两集光器舱底与载荷舱底**直接贴合**平台舱顶面（间隙 ≤0.05 m、嵌入 ≤0.05 m）；平台舱顶面上方对象清单恰为 {集光器A, 集光器B, 载荷舱} |
| D5 | 同层成排 | 载荷舱顶面与集光器舱顶面高差 ≤ 0.3 m |
| D6 | 金色包覆 | 除豁免件（镜筒、载荷舱、机构簇、太阳翼、储箱、出光窗口）外，一切可见结构件金色 MLI；非金色独立结构件 = 无 |
| D7 | 集光器翼折叠 | 每翼 4 板按 1→0、2→1、3→2 顺序 Z 折成摞、经 SADA 转至侧向贴平所属舱 ±X 侧面（**整摞外廓距舱面 ≤0.16 m**，v1.1 由 ≤0.10 放宽：4×0.03＋折缝）；翼摞 y-z 投影不超出舱体投影的 1.1 倍 |
| D8 | 合束器翼展开 | ±X 两翼各 4 板成直线自 SADA 外伸，**板面法向朝尾部 −Z（夹角 ≤30°，对日定向，v1.1 修订；"板面竖立"旧判作废）**，X 跨度 ≥3×舱宽 |
| D9 | 储箱朝向 | 集光器两只朝内（相对舱心偏移指向合束器）；合束器两只在 ±X 侧面 |
| D10 | 材质色 | 舱/架金、筒与载荷舱近黑、储箱乳白、翼蓝 |
| D11 | 包络 | 三器舱体外缘 max\|y\| ≤1.85 m，组合体总高 ≤4.61 m（记录并判定） |
| D12 | 渲染自检 | `out/assembly/` 四视角 PNG ≥1200×900 |

所有几何判定一律用**网格顶点真实包围盒**，不依赖对象原点；读取失败即 FAIL，禁止静默通过；`main()` 异常打印 traceback。

## 三、数值冲突处理原则

- **结构关系、构件有无、朝向**——以渲染图为准；
- **尺寸数值**——以 PPT 文字/指标表为准（基线 ~2.5 m 即此例：渲染图把两集光器画成相邻，不按图取 1.3 m，按文字取 2.3–2.6 m）；
- 渲染图之间互相矛盾时，以**已经验收的前序阶段**为准。
- 构型状态类结论（展开/收拢、有无连接件）必须挂证据（哪张图、哪一帧、哪页原文）；"物理自洽"式推断不得凌驾参考图。
