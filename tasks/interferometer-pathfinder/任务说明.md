# 任务说明：觅音计划 2028 干涉探测任务——集光器三维建模

## 背景

本目录素材来自《空间分布式极限探测重大任务（2026-09 公开版）》论证 PPT（第 50–59 页，任务一：干涉探测）的 CAD 渲染图与动画。该任务由 1 颗合束器＋2 颗集光器组成（"1+2"），2028 年 8 月以三器组合体状态一箭发射（CZ-3B、西昌），在日地 L2 晕轨道完成组合体短基线干涉测试后分离，展开为 20–100 m 基线自由编队。

## 本阶段目标（第一阶段）

**只做集光器单体的静态三维模型，交付 Blender Python 建模脚本**（脚本优先，可复现、可迭代；不要求 .blend 成品文件，不要动画）。

- 脚本应能用 Blender（3.6+ 或 4.x）直接运行：`blender --background --python collector.py`，运行后场景中生成完整集光器模型；
- 脚本末尾自带渲染自检：输出至少 4 个视角的 PNG（正交侧视、正交正视、斜俯视、顶部特写），存到本目录 `out/`；
- 建模后要**自己看渲染图与 refs/ 里的参考图比对**，迭代修正比例与构件位置，再交付。

## 后续阶段（本阶段不做，但结构设计要留余地）

1. 合束器单体建模（金色箱体＋顶部中央黑色圆台载荷舱）；
2. 三器组合体装配（在轨组合体测试状态：三器共机架、太阳翼展开，定长基线 ~2.5 m；发射收拢状态后续单列）——**以《阶段三_建模规格》《阶段三_验收清单》为准**；
3. 分布式编队场景（合束器居中，集光器分居两侧 20–100 m，星光粉色粗光束入射镜筒、器间红色细光束传输）；
4. 光束可视化与分离过程动画。

因此建议：集光器建模脚本模块化（平台舱、镜筒、随动机构簇、散热器、太阳翼各自成函数），构件参数（尺寸、位置、颜色）集中在文件头部的常量区。

## 验收与迭代（可检验目标）

**以同目录《验收清单.md》＋ `verify.py` 为准。** 每轮迭代执行：

```
blender --background --python collector.py
blender --background --python verify.py    # 自动检查 A1–A10，输出 out/verify_log.txt
```

全部 PASS 后，再按验收清单第二节把 `out/` 四张渲染图与 refs/ 主参考图逐张目检比对；有 FAIL 或目检不一致就改脚本重来，直到全部通过。交付物：collector.py、verify 全 PASS 日志、out/ 四视角渲染图、≤10 行中文说明（哪些按图还原、哪些是推断）。
