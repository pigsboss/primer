# 验收反馈 03：组合体第二次返工意见（2026-09-30）

答复对象：kimi code《阶段三_交付说明》。

**本反馈宣布作废两处前判**：《验收反馈 02》第 1、2 条意见（共机架两级堆叠＋太阳翼全部展开）与《阶段三_建模规格》§一.2 末句、§二 全节。审查方逐帧复核对 `refs/frames/opt_f040.png`（正视）、`组合体_整体渲染.png`、`组合体_顶部特写.png` 后确认：前两份文档把两个构型状态都判反了，现行 12/12 PASS 是把错误锁成"正确"——与《验收反馈 02》打回上一版时警告的失效机制完全相同。

## 一、两处硬伤

1. **接口错误：删掉 deck，集光器直连合束器平台舱。** 参考图（`组合体_整体渲染.png`、`组合体_顶部特写.png`、`frames/opt_f040.png`）中，两集光器金色舱体**直接坐在下层大金箱（合束器平台舱）的顶面上**，两器之间、器与下层箱体之间没有任何独立平板或梁件。PPT 第 51 页原文"2 个集光器与合束器**承力筒**相连"、第 57 页"3 个探测器**共机架**安装"——共机架就是合束器平台舱本体，《阶段三_建模规格》§一.2 自己也是这么写的（"合束器平台舱与共机架一体"），模型却做成了 deck 平板＋悬挂舱的三层结构。正确方案：集光器舱底经法兰/承力筒与平台舱顶面连接，连接段收于金色 MLI 包覆之内，整体**两层**。
2. **太阳翼状态错误：集光器翼折叠平贴，不是展开。** 特写与 `opt_f040.png` 正视图显示：集光器舱体 ±X 侧面是**平贴舱壁的电池阵面**（折叠收紧），集光器高度上没有任何伸出的翼片；真正展开的大翼只有下层合束器（中央）左右各一副。《验收反馈 02》"全部展开才物理自洽"的推断作废——**以参考图为准**，不做"物理自洽"式发挥。

**维持不变**：基线 2.366 m（判据 ∈ [2.3, 2.6]；PPT 第 56 页"~2.5 m 定长基线"文字优先）；金色包覆硬约束（不得有外露深灰/黑色独立结构件）；储箱朝向（集光器朝内、合束器 ±X 侧面）；不做光束与分离动画（阶段四）。

## 二、正确指引（新规格，取代《阶段三_建模规格》§一/§二 相应内容）

```
        ┌镜筒B┐  ┌载荷舱┐  ┌镜筒A┐     ← 上层：集光器B｜合束器载荷舱｜集光器A（同层成排）
        └──┬──┘  └──┬──┘  └──┬──┘
   ┌──────┴──────── 合束器平台舱（金色大箱，与共机架一体）────────┴──────┐   ← 下层：仅此一层
   │                    太阳翼（±X 展开，仅合束器一副）                     │
```

1. 删除 `deck`；两台集光器复用单体 `build()` 后置于 y = ±1.183，**舱底法兰直连平台舱顶面**：不悬空、不嵌入超过 0.05 m；法兰环 ≤0.05 m 高、金色、不外露结构本体。
2. 合束器载荷舱位于平台舱**顶面中央**（|y| ≤ 0.3，|x| ≤ 0.15），底面贴合，顶面与集光器舱顶高差 ≤ 0.3 m——顶视"镜筒—载荷舱—镜筒"一排（对照 `组合体_顶部特写.png`）。
3. 平台舱顶面上方除两集光器与载荷舱外**不得有任何对象**（承力筒藏于舱体与包覆内）。
4. 集光器太阳翼**折叠平贴**各自舱体 ±X 侧面（保留单体翼面的板格与蓝色材质，仅改姿态）；合束器太阳翼保持单体展开构型（±X 两翼、弦向竖立）。**不允许**为折叠翼新建深灰/黑色机构件——若需铰链/收纳件示意，一律金色并计入包络。
5. 包络记录：三器舱体外缘 max|y| ≤ 1.85 m（Φ3650），组合体总高 ≤ 4.61 m。

## 三、验收判据（照抄重写 verify_assembly.py，D1–D12 取代旧版，不得自增删）

- **D1 对象齐备且无独立连接件**：集光器×2、合束器平台舱、合束器载荷舱齐备；场景中不存在任何独立 deck/beam/truss/plate 类对象（按对象名与网格真实包围盒双重判定）。
- **D2 基线**：两 tube 轴线 y 之差 ∈ [2.3, 2.6] m。
- **D3 对称居中**：|y_A+y_B| ≤ 0.1；载荷舱 |y| ≤ 0.3、|x| ≤ 0.15。
- **D4 两层支撑**：两集光器舱底与载荷舱底直接贴合平台舱顶面（间隙 ≤0.05 m、嵌入 ≤0.05 m）；平台舱顶面上方对象清单恰好为 {集光器A, 集光器B, 载荷舱}。
- **D5 同层成排**：载荷舱顶面与集光器舱顶面高差 ≤ 0.3 m。
- **D6 金色包覆**：除豁免件（镜筒、载荷舱、机构簇、太阳翼、储箱、出光窗口）外，一切可见结构件金色 MLI；非金色独立结构件 = 无。
- **D7 集光器翼折叠**：两翼面与所属舱 ±X 侧面平行贴合（x 向间隙 ≤ 0.10 m），翼面 y-z 投影不超出舱体投影的 1.1 倍。
- **D8 合束器翼展开**：±X 两翼、板面竖立（弦向沿 Z），X 跨度 ≥ 3×舱宽。
- **D9 储箱朝向**：集光器两只朝内（相对舱心偏移指向合束器）；合束器两只在 ±X 侧面。
- **D10 材质色**：舱/架金、筒与载荷舱近黑、储箱乳白、翼蓝。
- **D11 包络**：三器舱体外缘 max|y| ≤ 1.85 m，组合体总高 ≤ 4.61 m（记录并判定）。
- **D12 渲染自检**：out/assembly/ 四视角 PNG ≥ 1200×900。

所有几何判定一律用**网格顶点真实包围盒**（反馈 02 第 7 条要求），不依赖对象原点；读取失败即 FAIL，禁止静默通过（第 8 条）；main() 异常打印 traceback（第 9 条）。

## 六、流程教训（备查，下不为例）

1. **构型状态类结论必须挂证据**：展开/收拢、有无连接件这类判断，规格里必须写明依据（哪张图、哪一帧、哪页原文），"物理自洽"式推断不得凌驾参考图之上——反馈 02 正是栽在这里。
2. **判据只验证"符合规格"，不验证"规格正确"**：构型级结论经同视角目检确认之前，不得固化为数值判据；固化错了，PASS 越多越自信地错。
3. **目检必须同视角对比**：正视对正视、俯视对俯视；iso 对概念图只能作辅助，不能作判据。
